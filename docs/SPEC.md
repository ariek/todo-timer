# やることクエスト 仕様書 v0.2

やることを片付けるためのブラウザゲーム。やることを「クエスト」（カテゴリー）に分けて登録し、1つずつタイマーでこなすと経験値が貯まり、レベルと称号が上がっていく。

## 0. 言葉の対応

| 画面での呼び方 | 意味 | 内部名 |
| --- | --- | --- |
| やること | 1件の用事。タイトル、難易度、繰り返し、日付、メモを持つ | task |
| クエスト | やることをまとめる箱（カテゴリー）。名前、色、アイコンを持つ | category |
| セッション | 「はじめる」から「やめる」までの一連の作業 | session |

以前の「片付けクエスト」では「クエスト = 1つのやること」「エリア = 箱」だったが、v0.2 で「やること = 1つのやること」「クエスト = 箱」に改めた。

## 1. 前提

- 利用者は自分ひとり。プロフィール切り替えは不要。
- 動作環境はスマホのブラウザを主とし、PCでも使える。
- サーバーなし。データはすべて `localStorage` に保存する。
- 素の HTML / CSS / JavaScript で作り、ビルド工程なし。GitHub Actions で `public/` だけを GitHub Pages に公開する。
- 見た目はやわらかい手描き風（パステル調、少しラフな線）。片付けや部屋に限定した表現（部屋の絵など）は使わない。
- 設計方針: やることをなるべく細かく分け、1つずつ片付ける（シングルやること）ことを最優先にする。機能を足すときもこの方針に沿うかを基準に判断する。

## 2. 画面構成

単一ページで、ヘッダーの1行がナビを兼ねる。「Lv. 称号」の札を押すと記録、右のアイコンで設定に切り替える（アイコンは文字なし。読み上げ用のラベルは持つ）。記録・設定を開いている間は、ヘッダーの札と設定アイコンを隠して右端に閉じるボタン（×）だけを出し、押すとクエスト一覧に戻る。クエスト一覧専用のボタンは持たず、下部のタブバーも持たない。起動時は前回最後に見ていたタブを開く（初回はクエスト）。最後のタブは `localStorage` の `todo-timer.lastTab` に、クエストタブで開いていた画面（一覧かやることか、どのクエストか）は `todo-timer.screen` に保存し、どちらもエクスポートには含めない。

| タブ | 内容 |
| --- | --- |
| クエスト | クエスト一覧画面と、そこから開くやること画面の2つを持つ。一覧は「すべて」と各クエストの行で、行をタップするとそのクエストのやること画面（先頭に「いまやる」カード、その下にやること一覧）に移る。やること画面からは上の帯の戻るボタンで一覧に戻る。ヘッダー（全画面共通）は1行。「Lv. 称号」の札を幅いっぱいに置き、右に設定のアイコン。札の背景そのものが経験値ゲージ（黄、左から満ち、境界線なし）で、札の右端に現在の経験値を太字で大きく、その横に「/ 次のレベルまで」を小さく出す。札を押すと記録画面に移る。記録・設定を開いている間はヘッダーに × だけを出し、押すとクエスト一覧に戻る。連続日数はヘッダーに出さない（記録画面の集計カードにある）。 |
| 記録 | カレンダー（月表示）、週間サマリー、セッションのランキング。 |
| 設定 | クエスト・やることの一括追加、データのエクスポート/インポート、初期化。クエストの編集シートはクエスト一覧画面から開く。 |

## 3. クエスト（カテゴリー）

やることをまとめる箱。すべてのやることはいずれかのクエストに属する。

- クエストは追加・名前変更・色の変更・アイコンの変更・並べ替え・削除ができる（クエスト一覧画面。編集シートで名前・色・アイコン・削除）。並べ替えは、行の右端のつまみ（≡）を押したまま上下に動かすドラッグ＆ドロップで行う（ポインターイベントで実装し、スマホでも指で動かせる。画面の端に近づくと少しスクロールする）。
- 色はパステルの8色から選ぶ（桃、黄、緑、水色、薄紫、ピンク、橙、灰）。アイコンは汎用の SVG セット（30種類程度: 仕事、家、本、ハート、カート、コイン、人、星、車、食事、ほうき、シャツ、電話、メール、PC、ダンベル、音符、旅行かばん、足あと、葉、書類、カレンダー、時計、旗、電球、工具、ギフト、カメラ、ゲーム、ペン など）から選ぶ。色とアイコンは別々に設定する。
- 色とアイコンは、クエスト一覧の行、やること画面の見出しと一覧の行、編集シートで共通に使い、見分けやすくする。
- クエスト一覧画面の行には、色付きのアイコン、名前、やることの件数を表示する（6章）。
- 既定のクエスト「なんでも」: 一括追加でクエストの指定がない行が入る先。なければ自動で作る（色は灰、アイコンは星）。
- 初期クエスト（サンプル）: 仕事、家事、勉強、健康、買い物。
- 削除時は所属やることをまとめて削除する（確認ダイアログあり）。

## 4. やること

やることをユーザーが自由に登録する。

### 4.1 項目

| 項目 | 説明 |
| --- | --- |
| やること（タイトル） | 例「経費精算を出す」。追加シートの項目名は「やること」 |
| クエスト | 所属クエスト（カテゴリー） |
| 難易度 | ★1 / ★2 / ★3。タイマーの長さは 3分 / 5分 / 10分（7章） |
| 繰り返し | なし / 毎日 / 毎週 / N日ごと |
| 日付 | 任意。繰り返しなしのやることに「いつまでに」を付けられる（画面上の言葉は「日付」）。繰り返しありのやることは完了時に自動で次回期限が入る |
| メモ | 任意。「いまやる」カードに表示するとき、文中の URL（http / https）はリンクになり、別ウインドウで開く（リンクを押しても編集シートは開かない） |

### 4.2 状態

- 繰り返しなしのやることは、完了すると「達成済み」になり一覧から消える（記録には残る）。
- 繰り返しありのやることは、完了後に次回期限が設定され、期限が来ると再び「やること」として表示される。
- 期限を過ぎたやることは「期限切れ」として強調表示する。
- 繰り返しなしで期限も未設定のやることは、常に「やること」として表示される。

### 4.3 いまやる1つ

一覧から選ぶ手間をなくし、1つずつ片付ける形にする。

- やること画面はクエスト一覧から開く。先頭の帯に、左に一覧へ戻るボタン（← のアイコンだけ）、中央に開いているクエストの名前（または「すべて」）を小さく出す。クエストを選ぶチップは置かない。
- 「すべて」では、「ほかのやること」をクエストの並び順で見出し付きに分けて表示する。各クエスト内の並びは標準と同じ。「いまやる」と次のやることも、この順（一番上のクエストから、クエスト内は標準の並び）で決める。1つのクエストを開いたときは、そのクエストのやることだけを標準の並びで表示する。セッションのまとめを閉じたあとは、やること画面のまま。開いているクエストにやることが残っていなければ「いまやる」の位置に空のカードを出す（一覧へは戻るボタンかナビで戻る）。文言は状況で変える: やることが1つもないときは「まだやることがありません」＋「下の『やることを追加』から、最初のやることを書き出そう」。今日やって空になったときは「クエストクリア！」＋「今日は N 件やり遂げました。おつかれさま！」＋「ほかのクエストをやる」ボタン（押すとクエスト一覧に戻る）。今日の分はなく次回待ちだけのときは「今日のやることはありません」＋「次回待ちのやることが来るまで、ひと休み」。
- その下に「いまやる」カードを1枚だけ大きく表示し、残りは「ほかのやること」として折りたたむ。カードにラベルや残り件数は出さない。コンボは2コンボ以上のときだけ、カードの右上に丸い札で出す。タイトルは札と重ならないように右側を空けて折り返す。
- 「ほかのやること」の並びは「いまやる」を決める規則と同じにし、上から順に次のやることになる。各行の右端のつまみ（≡）を押したまま上下に動かすと、同じクエストの中で並べ替えられる（別のクエストへは動かせない。セッション中はつまみを出さない）。先頭固定（今日スキップしていない期限切れ）の行はつまみを出さず、ほかの行をその上に置くこともできない。動かせる行が1つしかない一覧（移動先がない）でもつまみを出さない。並べ替えで「いまやる」は変わらない（いまやるは常にそのクエストの先頭のまま）。いまやるを替えたいときは「スキップ」でひとつ後ろに回すと、ほかのやることの先頭がいまやるになる。
- 「いまやる」はクエスト内の並びの先頭。クエスト内の並びは、期限切れ（日付が昨日以前）のやることが先頭に固定され、それ以外はやることの手動順（`order`。新しいやることは末尾）。固定の中の並びも手動順。期限が今日のやることや期限のある繰り返しやることも、期限を過ぎるまでは手動順に並ぶ。難易度は並びに使わない。
- 完了すると次の1つが自動で出る（7章の流れに従う）。
- 「スキップ」ボタンで、クエスト内でひとつ後ろに回せる（手動順を次のやることと入れ替え、一覧には「スキップ済み」と出る）。期限切れのやることが期限切れでないやることを飛び越えるときは、その日だけ先頭固定が外れる（日付が変わると固定に戻る。期限切れ同士の入れ替えでは外れない）。同じクエストにひとつ後ろの候補がないときは押せない。スキップで別のクエストのやることには移らない。タイマーが走っている間（一時停止中を含む）は押せない。
- 一覧の行には完了ボタンを置かない。完了は「いまやる」カードのタイマーからだけ行う（7章）。当日分の取り消しは「今日やった」から行える。行にはクエストの色とアイコンを付ける。
- 「ほかのやること」「今日やった」「次回待ち」「達成済み」は折りたためる。初期状態はすべて閉じる。「ほかのやること」と「今日やった」の開閉状態は `localStorage` の `todo-timer.sections` に覚えておき、次回も同じ状態で開く（エクスポートには含めない）。

### 4.4 一括追加（設定画面）

メモアプリや表計算ソフトに書き出したやることのリストをまとめて登録する。

- 設定画面の「クエスト・やることの一括追加」にテキストエリアを置き、1行1やることで貼り付ける。
- 行の形式は `クエスト：やること：日付：難易度：メモ`。区切りは全角「：」、半角「:」、タブのどれでもよく、1行の中で混ざってもよい（表計算ソフトから貼るとタブ区切りになる）。
- 項目の省略: 1項目だけならタイトル（クエストは「なんでも」）。2項目ならクエストとタイトル。3項目なら3つ目が難易度に見える（1〜3、★、☆）ときは難易度、そうでなければ期限。4項目以上ならクエスト、タイトル、期限、難易度、メモの順で、5項目目以降はすべてメモとして「：」でつないで残す。空欄は飛ばせる（`机：書類を仕分ける：：2` は期限なしで難易度2、`キッチン：換気扇：：3：洗剤を買う` はメモ付き）。
- 行頭行末と区切り前後の空白（全角スペース含む）は取り除く。行頭の箇条書き記号（`-` `*` `・` `•` `□` `[ ]` `1.` など）は外す。空行は無視する。
- タイトルの中の「：」は区切りと見なされる。タイトルに「：」を含めたいときはタブ区切りで書く。
- クエスト名が空、または区切りがない行は、クエスト「なんでも」に登録する。「なんでも」がなければ作る（色は灰、アイコンは星）。
- クエスト名が既存のクエスト（前後の空白を除いて完全一致）にあればそこへ、なければ新しいクエストを作る。新しいクエストの色は使われていない色から順に、アイコンは星。出てきた順に一番下へ追加する。
- 日付の書き方: `2026/9/20`、`9/20`（年なしは今日以降で直近のその日付）、`2026-09-20`、`9月20日`、`今日`、`明日`、`明後日`。期限はその日の 23:59:59 とする。
- 難易度の書き方: `1`〜`3`、`★`〜`★★★`、`☆`〜`☆☆☆`。省略時は 1。
- 繰り返しは指定できず「なし」。メモは200文字を超えたら切り詰める。
- タイトルが60文字を超える行は60文字に切り詰めて登録し、内訳に「切り詰め」として件数を出す。
- 読み飛ばす行: タイトルが空、日付が読めない、難易度が読めない、同じクエストに同じタイトルの未達成やることがすでにある（貼り付けた中での重複も含む）。
- 「読み込む」を押すと、まず内訳（新規クエスト、クエストごとの件数、切り詰めた行、読み飛ばした行とその理由）を表示し、「登録する」で確定する。
- 登録後は「N件を登録しました」と表示し、「取り消す」で今回追加したやることとクエストをまとめて戻せる（次の操作をするまで有効）。
- 登録ボーナスは1件ごとに +1 XP を付ける（5.1のルールどおり）。演出は控えめ。

### 4.5 操作

- 追加、編集、削除、完了、完了の取り消し（当日分のみ）。
- タイマーのセッション中（7章の「待機」以外の状態）は、やることの追加・編集・削除はできない。作業に集中させるため。行をタップしても編集シートは開かない。
- 完了時の演出とレベルアップの表示は、7章の「完了演出」モーダルで行う。やることの追加・削除の登録ボーナスは小さな札だけの控えめな演出。
- OS の「視差効果を減らす」設定が有効なときは、紙吹雪などの動きを省く。

## 5. ゲームルール

### 5.1 経験値とレベル

以下の数値はすべて仮置き。実際に使いながら調整する。

| 難易度 | 経験値 |
| --- | --- |
| ★1 | 15 |
| ★2 | 25 |
| ★3 | 50 |

- 完了時の経験値 = 難易度の基本値 + タイマーボーナス（7章）。以前の「タイマー中は1.5倍」は廃止。
- 登録ボーナス: やることを追加すると +1 XP、削除すると -1 XP（クエスト削除でまとめて消える場合も1件ごと）。1日の上限はなし。減らすときは 0 未満にはしないが、レベルの境目をまたげばレベルは下がる（完了の取り消しと同じ扱い）。記録画面のカレンダーやストリークには数えない。演出は完了より控えめ（小さな札のみ、紙吹雪なし）。
- レベルアップに必要な経験値は `100 × 現在レベル`。累積ではなく、レベルごとにゲージがリセットされる。
- レベルに応じて称号を付ける。

| レベル | 称号 |
| --- | --- |
| 1 | かけだし |
| 3 | 見習い冒険者 |
| 5 | 冒険者 |
| 8 | 熟練冒険者 |
| 10 | 達人 |
| 15 | 英雄 |
| 20 | 伝説 |

### 5.2 ストリーク

- 1日に1つ以上やることを完了すると、その日は「達成日」。
- 達成日が連続した日数をストリークとして表示する。
- 日付の切り替わりは端末のローカル時刻の 0時。
- 1日空くとストリークは 0 に戻る。救済措置は v0.1 では入れない。

## 6. クエスト一覧画面

- 1列の行をクエストの並び順で並べる。先頭に「すべて」の行、末尾に「クエストを追加」ボタン（右寄せ）。クエストが1つもないときは、やること画面の空のカードと同じ体裁で「まだクエストがありません」＋「下の『クエストを追加』から、最初のクエストを作ろう。設定の一括追加でまとめて作ることもできます」を出す（「すべて」の行は出さない）。
- 各行には、色付きのアイコン、名前、件数、編集ボタン（ペン）、並べ替えのつまみ（≡）を置く。行の影にクエストの色を使う。
- 件数は「やること」（期限切れ・今日・期限なしの合計。次回待ちは含まない）。期限切れがあれば「期限切れ N」を赤で添える。「すべて」の行は全クエストの合計。
- 進み具合のようなステータスは持たない。
- 行（名前の部分）をタップすると、そのクエストのやること画面に移る。「すべて」は全クエストのやること画面。
- 編集ボタンでクエストの編集シート（名前・色・アイコン・削除）を開く。追加ボタンで同じシートを新規で開く。
- つまみを押したまま上下に動かすと並べ替えられる。「すべて」の行は動かせず、その上にも置けない。

## 7. やることのタイマー

やること画面の「いまやる」カードにタイマーを組み込み、1つずつ時間を決めてこなす。完了はこのタイマーを通してだけ行う。カードの上部のタイトルと、その下のクエスト・難易度・繰り返し・日付の行は中央揃え（コンボの札がある間も中央を保つ）。

### 7.1 タイマー

- 長さは難易度で決まる: ★1 = 180秒、★2 = 300秒、★3 = 600秒。
- 円の中に残り秒数を大きく整数で表示する（例: 287）。分秒表記や「秒」の文字は出さない。円の縁が残り時間に応じて減る（実行中は残りの割合で 緑 → 黄緑 → 黄 → オレンジ → 赤 と変わり、一時停止はグレー、時間切れは赤）。
- 数字の下には高さ固定の枠を置き、状態に応じて次を入れる（数字の位置は状態が変わっても動かない）: 待機中は ▶（はじめる）、実行中は ⏸（一時停止）、一時停止中は ▶（再開）、時間切れは赤い「時間切れ」の札、次への待ちと休憩は空。アイコンは SVG で、ボタンは角の小さい四角に影を付けて札と区別する。
- ▶ / ⏸ / 時間切れの左に「−」、右に「+」を同じ大きさで置く。押すたびに10秒引く / 足す。表示は 0〜999 秒の範囲で、端に達したボタンは押せない。待機中はそのとき表示しているクエストの長さに効き、スキップなどで別のクエストに変わったら元に戻る。実行中・一時停止中・時間切れは今のタイマーに効く（時間切れからでも延長できる。0まで引くと時間切れになる）。増減した分もそのまま残り秒数として扱い、ボーナスの計算に含める。
- 円の下に主ボタンを大きく置く。待機中は「▶ はじめる」、開始後は「☑ できた！」（アイコンは SVG）。その下の中央に小さなボタンを置く。待機中は「スキップ」（クエスト内でひとつ後ろに回す）。待機中はカードのボタン以外の場所をタップすると、いまやるやることの編集シートが開く（一覧の行と同じ操作）。セッション中（実行中・一時停止中・次への待ち）は「× やめる」とその右に「スキップ」。セッション中のスキップは、いまのやることをひとつ後ろに回し、入れ替わったやることで5秒の待ちに入る（走っていたタイマーは捨て、コンボは続く。同じクエストにひとつ後ろの候補がなければ押せない）。完了はスタートしたあとにしかできず、次への待ちの間は押せない。
- 残り秒数が0になったら音とバイブで知らせ、タイマーは0で止まる。「完了」は押せるがボーナスはない（コンボは続く）。
- 一時停止してもボーナスとコンボは続く（残り秒数は止まったまま）。
- 開始時刻と一時停止の累計を保存し、残り秒数は差分で計算する。画面を閉じても進む（現状のタイマーと同じ）。
- 作業中（次への待ちから完了演出まで。一時停止中と休憩中を含む）は、「いまやる」カード以外（ヘッダーと下の一覧）に黒い半透明の板を敷いて操作できなくする。まとめの表示中は外す。起動時に作業中なら、必ずやること画面から始める。
- タイマーが走っている間（一時停止中を含む）は、ヘッダーに残り秒数を小さく表示する（作業中は覆いの下になるので、ほかの画面に移ったときの案内として残す）。

### 7.2 ボーナスとコンボ

- 時間切れになる前に完了すると、残り秒数 × 0.1 × コンボ倍率 を小数点以下切り上げしたボーナス経験値が付く。
- コンボは「セッション中に完了した回数」。時間切れの完了も数える。1コンボ目の倍率は 1.0、2コンボ目 1.2、3コンボ目 1.3、以降 0.1 ずつ増える（n コンボ目は 1 + 0.1 × n、ただし1コンボ目のみ 1.0）。上限なし。数列はあとで調整する前提。
- コンボは休憩、一時停止、時間切れをはさんでも続く。「やめる」でだけ0に戻る。
- 完了時の経験値 = 基本値（15 / 25 / 50）+ ボーナス。

### 7.3 セッションの流れ

最初に「はじめる」を押してから「やめる」までを1セッションとする。状態は次のとおり。

| 状態 | 内容 |
| --- | --- |
| 待機 | タイマー未開始。「はじめる」または円の中の ▶ を押すとセッションが始まり、「次への待ち」と同じ5秒のカウントダウン（音つき）を経てタイマーが動き出す |
| 実行中 | カウントダウン中。主ボタンは「クエスト完了」、円の中は ⏸ |
| 一時停止 | 円の中が ▶（再開）に変わる。「クエスト完了」も押せる（ボーナスとコンボは続く） |
| 完了演出 | 完了を押した瞬間に上昇する4音のチャイムを鳴らす。モーダルで経験値が足し上がるアニメーション（長さは行数で変わり、数字の動きが終わってから 2.1秒後に自動的に閉じる（基本のみ 3.4秒、ボーナスあり 4.3秒、コンボあり 5.2秒）。最後のクエスト（次がないとき）はさらに 1秒長い）。カードが弾んで紙吹雪が飛び、基本値 → ボーナス → コンボの行が順に現れて数字がカウントアップする。合計は「+」を小さく数値を大きく出し、カウントアップの段階ごとに拡縮して弾み、チャリンという音を鳴らす。最後にコンボの札ともう一度紙吹雪。レベルアップもここで見せる。終わると自動で閉じる |
| 休憩 | セッション開始（または前の休憩終了）から25分を超えていたら、完了演出のあとに5分の休憩に入る。モーダルで青いリングと残り秒数、「🔥Nコンボ 継続中」を表示し、操作は「休憩を終える」だけ。終わると音で知らせる |
| 次への待ち | 専用のカードで、次のやることのタイトルを大きく中央に出し、その下の行にタイマーの長さを「（180秒）」のように少し小さく出す。その下にクエスト・難易度・繰り返し・期限（例「家事 · ★ · 毎日 · 1日遅れ」）を小さく、その下に5秒のカウントダウンの数字を大きく出す。リング、完了ボタン、コンボの札は出さない。カードの高さは開始時のカードと必ず同じにする（開始時と同じ構造を透明な下敷きにして、その上に重ねる）。文字は縦の中央、「× やめる」「スキップ」は下端に寄せる。数字は変わるたびに手前からふわっと縮小しながら現れる。残り3・2・1秒で短い低い音を鳴らし、0で長い高い音とともに自動でスタートする（カーレースのスタートのように）。即スタートの操作はない。「スキップ」で次のやることを差し替えられる（5秒は数え直し） |
| まとめ | キラリンという上昇音とともに、セッションの結果（獲得経験値を大きく、達成数、最大コンボ、経過時間、ランキング順位）をモーダルで表示し、待機に戻る。上位5件に入ったら「自己ベストN位！」を出す |

- 「やめる」はセッション中いつでも押せる小さなボタン。確認ダイアログのあと、タイマーを止めてまとめを表示する。走っていたやることは未完了のまま残る。
- やることがなくなったら、完了演出のあとにまとめを表示してセッションを終える。
- 最後の操作から30分以上経ってアプリを開いたときは、セッションを自動で終えてまとめを表示する（実行中だったやることは未完了のまま）。
- 休憩は「25分を超えた最初の完了の直後」に入る。走っているやることは中断しない。休憩が終わったら25分の計測をやり直す。
- 待機中の「スキップ」は順番を変えるだけ。セッション中の「スキップ」は、順番を変えたうえで入れ替わったやることに進む。
- アプリを閉じている間は処理が動かないため、5秒のカウントダウンや休憩の終了は、次に開いたときに時刻から逆算して反映する。通知は出さない。

### 7.4 記録

- ログに基本値、ボーナス、コンボ数、タイマーの長さ、残り秒数を残す。記録画面の一覧に「+37（3コンボ）」のように出す。
- セッションの結果を履歴に残し、記録画面に獲得経験値の上位5件をランキングとして表示する（日付、経験値、達成数、最大コンボ）。

## 8. 記録

- カレンダーの下の「その日の記録」（見出しは「今日の記録」「9月12日（土）の記録」）の先頭に、その日のまとめを1行で出す: 達成数、最大コンボ、獲得経験値、作業時間。作業時間はその日に始めたセッションの開始から終了までの合計（一時停止や休憩を含む。今日を選んでいるときは進行中のセッションも含める）。1時間以上は「1時間23分」、未満は「45分」。その下に達成したやることの一覧。
- 上部に集計カード: 連続日数、最長連続、達成数の合計、獲得経験値の合計。
- 月カレンダー。達成日はマスに色を付け、完了数に応じて濃くする（1件 / 2〜3件 / 4〜5件 / 6件以上の4段階）。前後の月に移動でき、「今日」ボタンで戻る。
- カレンダーの日をタップすると、その日に達成したやることの一覧（時刻、タイトル、クエスト、経験値とそのうちのボーナス、コンボ数）を表示する。初期選択は今日。
- 週間サマリー: 今週（月曜始まり）の達成数、獲得経験値、活動日数、クエスト別の完了数（横棒）。
- ランキング（見出しは「ランキング」）: 獲得経験値の上位5件。日付、経験値、達成数、最大コンボを並べる。
- 削除されたやることの記録は「（削除されたやること）」として残す。

## 9. データ保存

### 9.1 保存先

- `localStorage` のキー `todo-timer.v1` に JSON を1つ保存する。
- 変更のたびに保存する。

### 9.2 データ構造

```json
{
  "version": 1,
  "player": { "xp": 0, "level": 1, "bestStreak": 0 },
  "categories": [
    { "id": "c1", "name": "仕事", "color": "sky", "icon": "briefcase", "order": 0 }
  ],
  "tasks": [
    {
      "id": "t1",
      "categoryId": "c1",
      "title": "経費精算を出す",
      "difficulty": 2,
      "repeat": { "type": "days", "every": 3 },
      "note": "",
      "deadline": null,
      "deferredAt": null,
      "unpinnedAt": null,
      "lastDoneAt": "2026-09-09T11:00:00+09:00",
      "dueAt": "2026-09-12T00:00:00+09:00",
      "done": false,
      "createdAt": "2026-09-09T10:00:00+09:00",
      "order": 0
    }
  ],
  "logs": [
    {
      "taskId": "t1",
      "doneAt": "2026-09-09T11:00:00+09:00",
      "xp": 37,
      "baseXp": 25,
      "bonusXp": 12,
      "combo": 3,
      "durationSec": 300,
      "remainingSec": 96,
      "prev": { "done": false, "lastDoneAt": null, "dueAt": null }
    }
  ],
  "session": {
    "startedAt": "2026-09-10T20:00:00+09:00",
    "cycleStartedAt": "2026-09-10T20:00:00+09:00",
    "lastActionAt": "2026-09-10T20:12:30+09:00",
    "phase": "running",
    "phaseStartedAt": "2026-09-10T20:12:30+09:00",
    "taskId": "t1",
    "durationSec": 300,
    "pausedTotalSec": 0,
    "pausedAt": null,
    "combo": 2,
    "maxCombo": 2,
    "completed": 2,
    "xp": 58
  },
  "sessions": [
    { "startedAt": "2026-09-09T21:00:00+09:00", "endedAt": "2026-09-09T21:40:00+09:00", "completed": 6, "xp": 143, "maxCombo": 4 }
  ],
  "sample": false
}
```

- `version` はアプリが 0.x の間は 1 のまま上げない。使っているのが自分だけなので変換処理は書かず、読み込み時に足りない項目は初期値で埋め、知らない項目（旧 `timer` など）は無視する。1.0 以降に形を変えるときから番号を上げて変換処理を書く。
- `session.phase` は `idle` / `running` / `paused` / `done` / `break` / `countdown` / `summary`。`phaseStartedAt` はその状態に入った時刻で、完了演出・休憩・5秒カウントダウンの経過はここから計算する。
- `logs[].xp` は基本値とボーナスの合計。`combo` はその完了が何コンボ目か（0 はボーナスなし）。

- `player.xp` は累計経験値。`player.level` は保存時に `xp` から計算して入れる（表示用。読み込み時は `xp` を正とする）。
- `sample` は初回起動のサンプルデータが入ったままかどうか。設定画面の「サンプルを消す」ボタンの表示に使う。

- `repeat.type` は `none` / `daily` / `weekly` / `days`。
- `deadline` は繰り返しなしのやることに任意で付ける期限。`dueAt` は繰り返しやることの次回期限で、どちらも未設定なら `null`。
- `deferredAt` はスキップした時刻。日付が今日のときだけ有効（「スキップ済み」の表示に使う）。
- `unpinnedAt` は期限切れのやることが、スキップで期限切れでないやることを飛び越えた時刻。日付が今日のときだけ先頭固定を外す。
- `order` は手動の並び順。同じクエストの中でだけ比べる。新しいやることは全体の最大値 + 1。編集でクエストを変えたときも最大値 + 1 にして、移った先の末尾に置く。スキップやドラッグで並べ替えたときは、動かした範囲のやることが持っていた値を小さい順に配り直す。ないものは読み込み時に登録順で埋める。
- `logs[].prev` は完了前のやること状態。当日中の取り消しで元に戻すために使う。
- 繰り返しやることの次回期限は、完了日の翌日（毎週なら7日後、N日ごとならN日後）の 0:00 にそろえる。
- 任意の期限（`deadline`）はその日の 23:59:59 とする。
- `categories[]` はクエスト（カテゴリー）。`color` は8色の名前（`peach` / `yellow` / `mint` / `sky` / `lav` / `pink` / `orange` / `gray`）、`icon` はアイコンセットの名前。`color` / `icon` がなければ既定値で埋める。
- 日付は ISO 8601 文字列で保存する。

### 9.3 エクスポート / インポート

- エクスポート: JSON をテキストエリアに表示してコピーできるようにする。ファイルダウンロードも用意する。
- インポート: JSON を貼り付けるか、ファイルを選択して読み込む。読み込み前に現在のデータを上書きしてよいか確認する。
- `version` が異なる場合は変換処理を通す（1.0 以降）。0.x の間は足りない項目を初期値で埋めるだけにする。

### 9.4 初期化

設定画面から全データを削除できる。二重確認する。削除後はクエストも含めて何もない状態になる（サンプルは入れない）。クエストは設定画面から追加するか、一括追加で自動的に作られる。

## 10. 初回起動

- サンプルのクエスト（仕事、家事、勉強、健康、買い物）とやることを数件入れた状態で始める。
- 「サンプルを消して自分で登録する」ボタンを設定画面に用意する。押すとやること、記録、レベルを消し、クエストは残す。

## 11. 非機能

- スマホ縦画面を基準に設計し、PC では中央寄せの幅固定で表示する。
- オフラインでも開けるよう、外部ライブラリは使わない。フォントは Google Fonts の丸ゴシック（Zen Maru Gothic）を1つだけ使い、読めないときはシステムの丸ゴシックにフォールバックする。
- 外部への通信はしない。
- 確認ダイアログは OS の `confirm` / `alert` を使わず、アプリの見た目に合わせた独自のモーダル（`dialog.js`）で出す。危険な操作の主ボタンは赤にし、外側のタップや Esc でキャンセル、Enter で決定。
- アイコン（画面のアイコンもクエストのアイコンも）は絵文字を使わず、`index.html` に置いた SVG のシンボル集を `<use>` で参照する。線は文字色（`currentColor`）、塗りは CSS 変数で変える。絵文字は端末ごとに形と大きさが違い、タブバーの高さがぶれる原因になったため。
- PWA として動く。マニフェストとサービスワーカーを持ち、ホーム画面に追加すると全画面で開ける。アプリ本体はキャッシュしてオフラインでも開けるようにし、フォントはキャッシュがあればそれを使う。
- 新しい版が配信されたら「新しい版があります」の帯を出し、「更新する」で切り替える。設定画面に版の表示と「更新を確認」ボタンを置く。
- 公開先は `https://ariek.github.io/todo-timer/` のようなサブパスなので、マニフェストとサービスワーカーのパスは相対で書く。
- iOS のステータスバー（時計の帯）は `default` にして iOS に描かせる。透過（`black-translucent`）は余白の値が 0 で返る不具合があり、ヘッダーが時計と重なるため使わない。帯の分だけ上が空くのは iOS の仕様として受け入れる。
- iOS は `apple-mobile-web-app-*` のメタ情報をホーム画面に追加した時点で固定するため、それらを変えたときはアイコンを削除して追加し直す必要がある。
- ページ全体は固定し、本文だけをスクロールさせる。ヘッダーは慣性スクロールで動かない。
- ピンチズームとダブルタップ拡大は効かせない（ビューポート指定に加えて、iOS 向けに `gesturestart` と2本指の `touchmove` を止める）。
- 全画面（ホーム画面から起動）のときはタブバーを低くし、下の余白はホームインジケーターと重ならない最小限にする。余白の値は JS で実測して CSS に渡す（iOS で `env()` を含む計算が効かないため）。
